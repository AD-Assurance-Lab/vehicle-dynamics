# Contributing

Corrections, clearer explanations, new examples and lab improvements
are welcome, especially from students who have taken the course.

## How
1. Open an issue for an error or an idea. Use the templates.
2. For a change, fork the repository, make the change on a branch, and open a
   pull request. The build check must pass.
3. Small fixes (typos, a wrong sign) can go straight to a pull request.

## Rules
- Only add figures and code you made yourself, or that carry a license allowing
  reuse (CC BY, CC0, public domain, Apache, MIT, BSD). Name the source and the
  license in the week README.
- Do not add quiz or exam content, solutions, grades, or anyone else's coursework.
- Every figure needs alt text. Every equation must be real text, not an image.
- By contributing you agree your work is licensed under CC BY 4.0 (documents)
  or Apache-2.0 (code). You are credited in the git history and in `NOTICE`.
