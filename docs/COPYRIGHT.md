# Copyright and privacy check (per week)

Run before a week's material is committed.

- [ ] Every figure is ours, openly licensed, or used with written permission.
      Source and license listed in the week README.
- [ ] No scans or screenshots of textbooks, papers or vendor documents unless
      the license allows redistribution.
- [ ] Third-party code keeps its license header and is listed.
- [ ] No student names, grades, IDs or student work (unless written consent is
      recorded).
- [ ] No quiz or exam content.
- [ ] Contributors credited in the week README and in `NOTICE`.
